# Sadeem Aljufran · Portfolio

AI Engineer (computer vision, agentic AI). Live site: https://sadeemai.github.io

Static site, no build step: `index.html`, `styles.css`, `main.js`, images in `assets/`.
Smooth scrolling uses [Lenis](https://github.com/darkroomengineering/lenis) from jsDelivr; everything else is vanilla JS.
All motion respects `prefers-reduced-motion`.

Run locally: `python -m http.server` in this folder, then open http://localhost:8000
