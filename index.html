Hakaya · حكايا

An AI storytelling game for children aged 5 to 12, where the controller is the child's own body. An agent writes a new story for each child, and the story only moves on when the webcam sees the child really jump, march, run, squat or swim.

19%of Saudi children get 60 active minutes a day (GASTAT 2025). The problem we set out to solve.

What I built

  • The movement model. MediaPipe Pose landmarks feed an LSTM with five independent yes/no outputs (jump, march, run, squat, swim), so a child standing still scores nothing.
  • An honest evaluation. A source-level train/test split (411 sources to train, 60 held out). It showed that an earlier 93% accuracy was inflated by data leakage.
  • The Movement Analysis module. It connects the webcam to the game: the model decides whether the child is moving, and body-motion signals count how many reps.
  • The integration. I wired the React web app to the FastAPI back ends for saved sessions, the parent dashboard and live difficulty adaptation, covered by a pytest suite.

How the system works

  • A LangGraph pipeline checks the art assets, picks two safe movements, and has a GPT-4o-mini Story Agent write the story. Rule-based checks then validate it.
  • A safety check on one webcam photo (YOLOv8 + MediaPipe) confirms light, free space and nothing nearby.
  • During play, a narrator voice reads the story, the camera verifies each movement, and the child earns a gold or bronze star.
  • An Adaptation Agent tunes the next challenge, capped at ±25% by rules.
