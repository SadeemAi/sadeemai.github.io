2026SDA Bootcamp capstone · team of 4Case study 02

Hakaya حكايا

Hakaya turns screen time into movement: an AI agent writes a new story for each child, and it only moves on when the webcam sees the child really jump, march, run, squat or swim.

hakaya

01Problem

19%

Only 19% of Saudi children get 60 active minutes a day.

Screens compete with movement. Hakaya makes the screen the reason to move.

02AI solution

A story agent, gated by a movement model.

An AI agent writes a new story for each child, and the story only moves on when the webcam sees the child really jump, march, run, squat or swim.

03How it works

The model decides whether. Body motion counts how many.

  1. Webcam
  2. MediaPipe Pose landmarks
  3. LSTM · 5 yes/no outputs
  4. Rep counter
  5. Story moves on
  • Designed and trained the movement model: MediaPipe Pose landmarks into an LSTM with five yes/no outputs, so a child standing still scores nothing.
  • Built the Movement Analysis module: the model decides whether the child is moving, and body motion counts how many reps, validated on 55 real clips.

04Tested honestly

An honest split beats a flattering score.

Tested it honestly with a source-level split (411 sources to train, 60 held out), which exposed an earlier 93% accuracy as data leakage.

411 train60

93% · leaked → honest held-out evaluation

05Product & impact

Shipped inside a real product.

Integrated the React web app with the FastAPI back ends: saved sessions, a parent dashboard and live difficulty adaptation.
